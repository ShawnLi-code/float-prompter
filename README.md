# 🎙️ 流光提词 (FloatPrompter)

> **专为短视频 / 小红书 / 视频号口播创作者打磨的轻量级安卓悬浮提词器**  
> 告别市面上收费/套路满满的提词 App，完全由自己掌控，无广告、无内购、支持一键拖拽与原生相机完美融合。

---

## ✨ 核心特性

1. **🪟 自由拖拽与吸附**：
   - 悬浮在任意相机应用上层（尤其搭配手机自带的高清原生相机取景）；
   - 随手拖拽到前置摄像头正下方，视线直对镜头，眼神完全不露馅。
2. **🕶️ 毫秒级透明度调节**：
   - 支持 35%、65%、90% 快速预设，半透明黑色磨砂底，既能看清自身表情和构图，也能清晰辨识高亮台词。
3. **⚡ 智能断句与窄窗排版引擎**：
   - 导入或粘贴原始长文稿后，**一键自动过滤括号动作提示（如：看一眼镜头、苦笑）**；
   - 智能切分为每行 8~12 字的黄金视线窄句，眼球不左右晃动，阅读极其轻松。
4. **⏱️ 双模滚屏（匀速调速 + 麦克风跟读）**：
   - **定时匀速滚屏**：1~10 档随心调速，支持轻触暂停、双击复位；
   - **语音跟读**：调用系统语音识别，读到哪句高亮滚到哪句，读慢了不抢跑，读快了不掉队。
5. **🚀 GitHub Actions 自动打包发布**：
   - 只要推送代码，GitHub 云端自动化编译并生成 Release APK，手机浏览器一键下载安装！

---

## 🛠️ 本地与云端构建

### 1. 云端构建（推荐，最省心）
- 创建 GitHub 仓库（例如 `float-prompter`）并关联；
- 执行 `git push origin main` 或推送标签 `git tag v1.0.0 && git push origin v1.0.0`；
- 在 GitHub 仓库的 **Actions** 或 **Releases** 标签页，直接下载 `FloatPrompter-v1.0.0.apk` 到手机上安装即可。

### 2. 本地 Gradle 命令行构建
```bash
gradle assembleRelease
# 生成 APK 位置: app/build/outputs/apk/release/app-release.apk
```
